# ПроДА — Прокурорский Документ-Ассистент

**Конвертация PDF в PNG и объединение изображений на Windows 10/11.**

ПроДА помогает преобразовывать PDF в изображения, объединять фотографии и автоматически сохранять результаты в выбранные папки. Все документы обрабатываются локально, без загрузки в интернет.

## Возможности

### Конвертация PDF → PNG

- Добавление нескольких PDF через кнопку выбора файлов или перетаскивание.
- Очередь обработки с прогрессом и статусом каждого документа.
- Преобразование каждой страницы в отдельный PNG.
- Конвертация всех страниц или выбранного диапазона.
- Качество: **150, 200 или 300 DPI**, по умолчанию — 200 DPI.
- Настройка ширины и высоты изображения. По умолчанию ширина — **600 пикселей**, высота рассчитывается пропорционально. Заданные размеры определяют итоговое разрешение PNG.
- Возможность задать своё название файлов перед конвертацией.
- Автоматическое объединение выбранных страниц каждого PDF по горизонтали в дополнительный PNG. Отдельные страницы также сохраняются.

### Профили сохранения

- Несколько именованных профилей со своими папками назначения.
- Общий профиль для очереди или отдельный профиль для каждого PDF.
- Создание отдельной подпапки для каждого документа.
- Шаблоны имён с переменными:

| Переменная | Значение |
| --- | --- |
| `{name}` | Имя исходного PDF без расширения |
| `{page}` | Номер страницы с ведущими нулями: `001`, `002`, `003` |
| `{date}` | Дата в формате `YYYY-MM-DD` |
| `{prefix}` | Текст, заданный в настройках профиля |

Настройки и последний выбранный профиль сохраняются между запусками.

### Объединение изображений

- Отдельная вкладка **«Объединение PNG»**.
- Поддержка PNG, JPG, BMP, TIFF и WebP; многостраничные изображения не поддерживаются.
- Объединение по горизонтали или вертикали.
- Изменение порядка изображений перед сохранением.
- Сохранение результата в PNG без масштабирования исходных изображений.
- От 2 до 200 изображений; итоговый размер — до 40 мегапикселей и до 100 000 пикселей по стороне.

### Интерфейс и дополнительные функции

- Русский язык и читаемый шрифт Segoe UI.
- Три темы: **тёмная**, **светлая** и **«Няшная»**.
- Анимированный фон и возможность отключить анимации.
- Звуки клика, завершения обработки, ошибки и пасхалки с баклажаном.
- История конвертаций и повторный запуск задач.
- Кнопка открытия папки с результатами.
- Панель **«Что нового»** с историей изменений версий.
- Игра **«Динозаврик»** с локальным рекордом.

## Установка

1. Откройте раздел **Releases** этого репозитория.
2. Скачайте установщик нужной версии, например `PRODA-Setup-2.4.0-x64.exe`.
3. Запустите установщик и следуйте инструкциям.
4. Откройте **ПроДА** через меню «Пуск» или созданный ярлык.

**Python и дополнительные библиотеки устанавливать не нужно.**

Системные требования: **Windows 10/11, 64-разрядная версия**. Установщик не подписан цифровой подписью.

## Быстрый старт

### Преобразовать PDF в PNG

1. Откройте вкладку **«Конвертация PDF»**.
2. Добавьте документы кнопкой **«Выбрать PDF…»** или перетащите их в окно.
3. В настройках профиля выберите папку для результатов.
4. При необходимости задайте диапазон страниц, качество, размеры и название файлов.
5. Нажмите **«Конвертировать»**.
6. После завершения нажмите **«Открыть папку с результатом»**.

Для автоматического объединения страниц включите галочку **«Объединять страницы каждого PDF по горизонтали»**. Каждый PDF объединяется отдельно; для одной выбранной страницы дополнительная копия не создаётся. При большом количестве страниц результат становится очень широким: просматривая его целиком, вы увидите мелкий текст. Само объединение не уменьшает разрешение отдельных страниц.

### Объединить изображения

1. Откройте вкладку **«Объединение PNG»**.
2. Добавьте минимум два изображения.
3. Установите порядок кнопками **«Выше»** и **«Ниже»**.
4. Выберите горизонтальное или вертикальное направление.
5. Нажмите **«Объединить и сохранить…»** и выберите путь результата.

### Сыграть в «Динозаврика»

| Действие | Управление |
| --- | --- |
| Начать игру / прыгнуть | Пробел, стрелка вверх или клик по игровому полю |
| Пауза / продолжить | `P`, `Esc` или кнопка паузы |
| Начать заново | Кнопка «Начать заново» |

Перепрыгивайте препятствия: скорость постепенно увеличивается. При смене вкладки игра автоматически приостанавливается. Рекорд сохраняется на этом компьютере.

## Работа с файлами

- Исходные PDF и изображения не изменяются и не удаляются.
- Существующие результаты не перезаписываются молча: при совпадении имени добавляется числовой суффикс.
- При отмене уже готовые изображения остаются на диске.
- Ошибка одного PDF не останавливает обработку остальных документов очереди.
- Для защищённых PDF запрашивается пароль; пароль не сохраняется.
- Настройки и история хранятся в `%APPDATA%\PDFtoPNG`.

## Версия и обновления

Текущая версия: **2.4.0**.

В этой версии добавлены карточки истории обновлений и игра «Динозаврик», исправлены углы подсказки баклажана.

Автоматическое скачивание обновлений **пока не реализовано**. Новые версии нужно скачивать вручную из раздела **Releases**.

Вкладка **«Проверка документов»** временно исключена для доработки. Проверка текста, OCR и связанные инструменты в текущую сборку не входят.

## Сторонние компоненты

Приложение использует Python, PySide6 / Qt, PDFium и Pillow. Основной код сборки компилируется с помощью Nuitka. Лицензии и уведомления сторонних компонентов включены в дистрибутив.
